# 1. 要件定義（Requirements）
目的：どのような機能を持ったプログラムにするかを明確にする。
- 対戦形式: ユーザー対コンピュータの1対1。
- 入力形式: 「グー、チョキ、パー」の文字列、または「1, 2, 3」の数字の両方を受け付ける。
- 勝敗ルール: 標準的なじゃんけんのルールに基づき、勝ち・負け・あいこを判定する。
- エラー処理: 規定外の入力があった場合、エラーを表示して再入力を促す。
- 戦績管理: ゲーム終了まで、累計の勝利・敗北・引き分け数を記録する。
- 継続機能: 1回ごとに「もう一度遊ぶか」を選択でき、終了時に最終戦績を表示する。


# 2. 設計の概要（Design)
目的：要件を実現するためのプログラムの構造を決める。
- データ構造:
  - 手の情報を辞書型（dict）で管理し、入力値（1やグー）を共通の数値（0, 1, 2）に変換して判定しやすくする。
  - 戦績を保持するための変数（wins, losses, draws）を用意する。
- メインループ:
  - while 文を使用して、ユーザーが「終了」を選択するまでゲームを繰り返す。
- ロジック（勝敗判定）:
  - random.randint でコンピュータの手を決定。
  - if / elif 文、または数学的な計算（例：$(player - computer) \pmod 3$）を用いて、効率的に勝敗を判定する。
- 終了処理:
  - ループを抜けた際に、これまでの戦績を整形して画面に出力する。
