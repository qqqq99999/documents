プログラミングを嗜むための「環境構築」の手引き
皆様、ごきげんよう。学校のPCを使い、優雅に開発環境を整えてまいりましょう。 もし道に迷われましたら、AIやGoogleの叡智をお借りになるのがよろしいかと存じます。それでも解決いたしません時は、わたくしにいつでもお聞きくださいまし。

# 1. VS Code（エディタ）の導入
まずは、魔法の杖となるエディタを手に取りましょう。

## 1. Microsoft Storeを起動

- Windowsキーを押し、検索窓に「Microsoft Store」と入力して開きます。

## 2. VS Codeを検索

- ストア内の検索窓に「vscode」と入力し、Enterを押します。

## 3. インストール

- 青いアイコンを選択し、「インストール」ボタンをクリックいたします。

**【参考】** 詳しい手順は[こちらの記事(Qiita)](https://qiita.com/YurimyMiyu/items/5ce7821f1e3e5905c3ee)にございますわ。

# 2. 拡張機能の追加
1. VS Codeを使いやすくカスタマイズいたします。

2. VS Codeを開き、左端の**「四角が4つ集まったアイコン」**を選択します。

検索窓から以下の名前を入力し、「Install」を押してくださいまし。

- **Japanese Language Pack**: 画面を日本語に翻訳いたします。

- **Live Share**: 殿方やご友人とリアルタイムでコードを共有できますわ。

# 3. Git（バージョン管理）の準備
書いたコードの歴史を保存するためのツールです。

1. VS Code上で Ctrl + Shift + G を押すか、左側の**「分岐したようなアイコン」**を選択します。

2. 「Gitをインストール」という案内が表示されますので、そちらをクリック。

3. 公式サイトへ飛びますので、基本的には**「Next」を押し続けて**インストールを完了させましょう。

# 4. GitHubの嗜み
作成した作品を世界（あるいは自分専用の倉庫）に保存するための場所です。

[GitHub公式サイト](https://github.com/)へ向かい、サインイン（未登録ならサインアップ）を済ませます。

VS Codeの左下にある**人型のアイコン**からGitHubへサインインし、連携を済ませておくと、後の作業が大変スムーズですわ。
